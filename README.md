# Drop Domino しずくドミノ

水玉をタップしてふくらませ、破裂したしずくで連鎖させて盤を空にするパズルゲームです。ブラウザで遊べます（スマホのタップ・PC のマウスとキーボード）。

遊ぶ：https://mesomush.github.io/drop-domino/

- エンドレス：1つの水タンクでどこまで進めるか挑戦。盤は 8×8 まで広がり、特殊な水玉・ブロック・床の仕掛け・アイテム・大波が出てきます。100面で完走すると2周目へ。途中で閉じても「続きから」遊べます
- 今日のエンドレス：その日はみんな同じ盤。日替わりのお題3つつき
- 今日の1問：毎日1問、最少手数で消す。連続日数・お休み券・過去の問題
- 詰めパズル：100問（ソルバーで全問、最少手数を確かめてあります）
- 練習：好きな物を置いて試せる盤。作った盤は URL で渡せます
- 記録・実績：最高記録・最近の10回・小さなしるし（実績）26個

記録は遊んでいるブラウザの中だけに残ります。
